GET STARTED

Chạy BLACKTRACE trên Termux

Clone repository, chạy installer rồi bắt đầu từ BLACKTRACE Academy.

git clone https://github.com/khahdihdz/blacktrace-termux.git cd blacktrace-termux chmod +x install.sh ./install.sh blacktrace
⚠️ Môi trường an toàn

BLACKTRACE là game mô phỏng. Các IP, domain, username, log và kết quả công cụ được thiết kế để luyện tập; game không thực hiện quét hoặc truy vấn mục tiêu thực.
